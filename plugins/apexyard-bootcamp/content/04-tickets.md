# Tickets

## Request a feature

A feature ticket describes new behavior. State the user need and the acceptance criteria.
Try: /feature Corner Shop delivery fee
Check: skill feature
Done: You filed the feature ticket.

## Report a bug

A bug ticket describes incorrect behavior. Give the expected result and the steps that reproduce the fault.
Try: /bug Corner Shop basket total is incorrect
Check: skill bug
Done: You filed the bug ticket.

## Describe a task

A task ticket describes technical work. State the reason, scope, and checks.
Try: /task Corner Shop improve basket tests
Check: skill task
Done: You filed the task ticket.

## Start one ticket

Run /start-ticket with a real ticket number. The active ticket connects code edits to the approved work.
Try: /start-ticket <ticket-number>
Check: skill start-ticket
Done: You started the ticket.
Note: Replace placeholders with real ticket numbers. Keep one ticket active.
