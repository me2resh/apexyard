# Diagrams

## Show the system

Use /c4 to show Corner Shop users, external systems, and containers. A container is a deployable application unit.
Try: /c4 corner-shop
Check: skill c4
Done: You drew the C4 diagrams.

## Show the process

Use /process to show how Corner Shop handles an order. Compare the diagram with the actual business steps.
Try: /process corner-shop
Check: skill process
Done: You drew the order process diagram.

## Show the sequence

Ask for a sequence diagram in plain words. Show the order of calls during Corner Shop checkout.
Try: draw a sequence diagram for Corner Shop checkout
Note: No dedicated sequence skill exists. Review the generated diagram with the class.

## Show the data flow

Use /dfd to show data flows and trust boundaries. A trust boundary separates systems with different access controls.
Try: /dfd corner-shop
Check: skill dfd
Done: You drew the data flow diagram.
