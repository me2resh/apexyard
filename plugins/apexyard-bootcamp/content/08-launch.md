# Launch

## Check readiness

Use /launch-check before you launch Corner Shop. Read each result and resolve blocking findings.
Try: /launch-check corner-shop
Check: skill launch-check
Done: You ran the launch readiness check.

## Check accessibility

Use /accessibility-audit to check how customers use Corner Shop. Resolve barriers that prevent access.
Try: /accessibility-audit corner-shop
Check: skill accessibility-audit
Done: You ran the accessibility audit.

## Check performance

Use /performance-audit to inspect Corner Shop load time and runtime behavior. Record measured results.
Try: /performance-audit corner-shop
Check: skill performance-audit
Done: You ran the performance audit.

## Check monitoring

Use /monitoring-audit to check alerts and health checks. Confirm who responds when Corner Shop fails.
Try: /monitoring-audit corner-shop
Check: skill monitoring-audit
Done: You ran the monitoring audit.

## Review the launch evidence

Check the audit results with the team. Use /compliance-check and /docs-audit when the launch needs those checks.
Note: Choose additional audit skills from the actual project needs.
