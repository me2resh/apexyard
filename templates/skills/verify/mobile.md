# Verify skeleton — Mobile

Use the controlled technical writing profile for evidence.
Use this file with `templates/skills/verify/SKILL.md`. Fill in its setup fields first.

## Start the app

Check the platform SDK and required runtime, including the JDK for Android.
Build and launch the app on a named emulator, simulator, or attached test device.
Record the device name and operating system version.

## Drive the main flows

Drive the main flow through UI automation on the recorded device.
Check the changed screen and one relevant error path.
Capture screenshots and relevant device logs.

## Print evidence

Report the build command, its exit code, and the recorded device.
Report each flow, its expected result, and its observed result.
Report each screenshot and log path.
Report missing SDKs, devices, or automation tools as blockers.
