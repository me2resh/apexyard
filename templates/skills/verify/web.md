# Verify skeleton — Web

Use the controlled technical writing profile for evidence.
Use this file with `.claude/skills/verify/SKILL.md`. Fill in its setup fields first.

## Start the app

Start the local web server with the project's documented command.
Record the server's URL and working directory.
Confirm readiness within a bounded timeout before driving flows.

## Drive the main flows

Open the recorded URL in an available browser automation tool.
Drive the primary user journey through its visible controls.
Check the changed screen and one relevant error path.
Capture screenshots with file paths and observed results.

## Print evidence

Report the readiness command, its exit code, and the server URL.
Report each flow, its expected result, and its observed result.
Report each screenshot path.
Report a browser blocker when browser automation is unavailable.
